# ✊✋✌️ Stone Paper Scissors Game

An interactive **Stone Paper Scissors** game built using **HTML**, **CSS**, and **JavaScript**. The game allows users to play against the computer with real-time score tracking, dynamic result messages, and an engaging user interface.

## 🚀 Features

- 🎮 Play against the computer
- 🎲 Random computer move generation
- 🏆 Win, Lose, and Draw detection
- 📊 Live scoreboard for player and computer
- 💬 Dynamic result messages
- 🎨 Color-coded feedback for game outcomes
- 📱 Responsive and user-friendly interface

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (ES6)

## 🎮 How to Play

1. Clone the repository:

```bash
git clone https://github.com/the-rahul-07/Stone-Paper-Scissor.git
```

2. Navigate to the project directory:

```bash
cd Stone-Paper-Scissor
```

3. Open `index.html` in your browser.

4. Choose **Stone**, **Paper**, or **Scissor** to play against the computer.
